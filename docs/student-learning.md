# تجربة تعلّم الطالب

هذه المرحلة تغطي لوحة الطالب بعد تفعيل الدورة: نظرة عامة، دوراتي، صفحة الدورة، صفحة الدرس، والتقدم.

## Dashboard

`GET /api/dashboard/summary` يعيد أرقاماً حقيقية فقط:

- عدد الدورات النشطة القابلة للتعلم
- الدروس المكتملة مقابل إجمالي الدروس المنشورة في تلك الدورات
- طلبات الاشتراك المفتوحة
- آخر نشاط تعليمي
- `ContinueLearning` إن وُجد

الواجهة في `/dashboard` تعرض بطاقات مختصرة من هذا المصدر فقط، دون إحصاءات مخمّنة.

## My Courses

`GET /api/enrollments` يعيد كل انتسابات الطالب مع نسبة التقدم ودرس المتابعة.

حالات العرض بالعربي:

- `Active` وصالحة زمنياً → فعالة، ويمكن فتح الدروس
- `Active` مع `ExpiresAt` في الماضي → منتهية
- `Suspended` → معلقة
- `Revoked` → مسحوبة
- `Expired` → منتهية

الدورات النشطة تظهر أولاً. الدورات السابقة (منتهية / معلقة / مسحوبة) تظهر في قسم مستقل. لا يظهر زر متابعة التعلم إذا لا توجد صلاحية.

## Course Access

صلاحية التعلم الفعلية تمر عبر `ICourseAccessService.CanUserAccessCourseAsync`:

```text
Status == Active
AND (ExpiresAt == null OR ExpiresAt > UtcNow)
```

وجود بطاقة في لوحة التحكم لا يكفي. طلب `GET /api/student/courses/{slug}` أو صفحة الدرس بدون صلاحية يعيد `403`.

دورة مؤرشفة مع Enrollment نشط تبقى ظاهرة وقابلة للتعلم. الاستعلام لا يشترط `Course.Status == Published` للانتساب القائم.

## Progress

التقدم تعليمي فقط، ولا يمنح صلاحية إضافية.

- `PUT /api/progress/{lessonId}` يقبل `WatchedSeconds` فقط.
- القيمة تُثبَّت عند `0` كحد أدنى.
- إذا `DurationSeconds > 0` تُقصّ إلى مدة الدرس. إذا المدة صفر يُعتمد سقف 24 ساعة حتى لا تُحفظ أرقام غير منطقية من لاعب مستقبلي غير دقيق.
- التحديث أحادي الاتجاه: `MAX(القيمة الحالية، القيمة الجديدة)` حتى لا يرجّع طلب قديم المشاهدة إلى الخلف.
- `GET` لا يغيّر `LastWatchedAt`. يُحدَّث فقط مع PUT أو Complete.
- لا يكتمل الدرس تلقائياً عند الوصول لنهاية المشاهدة في هذه المرحلة. الإكمال يدوي عبر `POST /api/progress/{lessonId}/complete`.
- الإكمال Idempotent: لا يُنشأ صف ثانٍ.
- `ProgressPercent = floor(الدروس المنشورة المكتملة / إجمالي الدروس المنشورة × 100)`. المسودات والأرشيف خارج الحساب. إذا الإجمالي صفر فالنسبة صفر.

## Continue Learning

ترتيب اختيار الدرس:

1. آخر درس غير مكتمل يملك `LastWatchedAt`.
2. إن لم يوجد: أول درس غير مكتمل حسب `Section.SortOrder` ثم `Lesson.SortOrder`.
3. إن اكتملت الدورة: أول درس منشور للمراجعة.

على مستوى اللوحة، يُختار من الدورات المتاحة الدرس ذو أحدث `LastWatchedAt`، وإلا أحدث دورة حسب `StartedAt`.

## Completion

إذا اكتملت كل الدروس المنشورة تظهر النسبة 100% ورسالة «أكملت الدورة». لا شهادات في هذه المرحلة.

## Archived Course

الطالب الذي يملك Enrollment نشطاً يبقى قادراً على فتح الدورة ودروسها حتى لو أصبحت الدورة Archived ولم تعد ظاهرة في الكتالوج العام.

## Expired / Suspended

- منتهية: لا تفتح صفحة التعلّم ولا التشغيل ولا تحديث التقدم.
- معلقة: نفس الرفض، مع رسالة «الوصول إلى هذه الدورة معلّق» ورابط تواصل.
- مسحوبة: رسالة عامة دون تفاصيل إدارية.
